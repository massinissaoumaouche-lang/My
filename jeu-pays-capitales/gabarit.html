Tableau de câblage

Ce câblage est fixe : il ne change jamais, quel que soit le thème ou la grille d'étiquettes. Chaque fil relie une seule douille P à une seule douille C. Coche la case après avoir testé le fil.

Schéma électrique (version 9 V, 3 lampes en série)

Tests avant de fermer

  1. Pince A contre pince B, interrupteur sur marche : les 3 lampes s'allument. Sinon : ampoule dévissée, pile vide, domino desserré.
  2. Les 20 bonnes paires (tableau ci-dessus) : allumé à chaque fois. Sinon : fil mal serré ou mauvais trou.
  3. Les voisins : P1–P2, P2–P3, …, P19–P20, puis C1–C2, …, C19–C20 : éteint. Sinon : deux œillets ou deux fils nus se touchent.
  4. Interrupteur sur arrêt, pinces ensemble : éteint.

Plan de pose des étiquettes

Planche 300 × 400 mm vue de face, dessin à l'échelle 1:2. Cotes en mm depuis le coin haut gauche. Les étiquettes laissent libres le titre, les 3 lampes, l'interrupteur, les sorties A et B, et 5 mm autour de chaque tige pour la pince.

Étiquettes

Imprimer à 100 % (taille réelle, pas « ajuster »). Contrôle : une étiquette de nom mesure 63 mm de large. Découpe, puis colle à la pâte adhésive selon le plan de pose : le code P… / C… dans le coin indique la tige.
