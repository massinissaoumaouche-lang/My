Tableau de câblage

Ce câblage est fixe : il ne change jamais, quel que soit le thème ou la grille d'étiquettes. Chaque fil relie une seule douille P à une seule douille C. Coche la case après avoir testé le fil.

Schéma électrique

Tests avant de fermer la boîte

  1. Sans appuyer sur le bouton : rien ne s'allume, quoi que fassent les sondes.
  2. Bouton appuyé, sondes en l'air : LED rouge allumée. Sinon : LED rouge à l'envers, ou transistor mal branché.
  3. Bouton appuyé, sondes l'une contre l'autre : LED verte + buzzer, rouge éteinte. Si la rouge reste allumée : R3 ou transistor mal branché (vérifier l'ordre des pattes).
  4. Les 20 bonnes paires (tableau ci-dessus) : vert à chaque fois. Sinon, fil mal serré ou coupé.
  5. Les voisins : sonde A sur P1 et sonde B sur P2, puis P2–P3, …, P19–P20, puis C1–C2, …, C19–C20 : rouge à chaque fois. Du vert ici veut dire que deux fils voisins se touchent (brin de cuivre qui dépasse, écrou qui touche le voisin).
  6. Quelques mauvaises paires au hasard (ex. P1–C1, P5–C6) : rouge.

Étiquettes

Découpe sur les pointillés, colle chaque étiquette (pâte adhésive) dans la case qui porte le même code (P… / C…) sur le panneau. Pour une nouvelle partie : clique « Nouvelle grille », imprime cette page, remplace les étiquettes. Le câblage ne change pas.
