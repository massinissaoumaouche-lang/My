Tableau de câblage

Ce câblage est fixe : il ne change jamais, quel que soit le thème ou la grille d'étiquettes. Chaque fil relie une seule douille P à une seule douille C. Coche la case après avoir testé le fil.

Schéma électrique

Tests avant de fermer la boîte

  1. Sondes l'une contre l'autre : la LED s'allume et le buzzer sonne. Sinon, problème dans le circuit pile / résistance / LED (LED à l'envers ?).
  2. Les 20 bonnes paires (tableau ci-dessus) : chacune doit allumer. Sinon, fil mal serré ou coupé.
  3. Les voisins : sonde A sur P1 et sonde B sur P2, puis P2–P3, …, P19–P20, puis C1–C2, …, C19–C20. Tout doit rester éteint. Une lumière ici veut dire que deux fils voisins se touchent (brin de cuivre qui dépasse, écrou qui touche le voisin).
  4. Quelques mauvaises paires au hasard (ex. P1–C1, P5–C6) : éteint.

Étiquettes

Découpe sur les pointillés, colle chaque étiquette (pâte adhésive) dans la case qui porte le même code (P… / C…) sur le panneau. Pour une nouvelle partie : clique « Nouvelle grille », imprime cette page, remplace les étiquettes. Le câblage ne change pas.
